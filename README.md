# Generation Watch — Global Protest & Youth Movement Observatory

**Tagline:** *Understand the movements shaping our world.*

Generation Watch is an independent, nonpartisan research and educational observatory built to examine protest events, civil resistance campaigns, student and labour mobilisation, human consequences, and national socioeconomic context across the globe.

---

## 1. Architecture & Technology Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Leaflet (interactive cartography), Apache ECharts (statistical figures), PapaParse (CSV/TSV inspection), and Lucide icons.
- **Backend:** Node.js + Express (`server.ts`) providing REST endpoints, upstream request throttling, TTL caching, CSV staging/normalization, and Vite middleware.
- **Persistence:** Clean repository data-access layer (`src/services/researchStorage.ts`) backed by IndexedDB (`idb`) so imported historical datasets, researcher-authored movement profiles, cached indicators, and verification reviews persist across browser sessions without requiring paid external databases.
- **Zero AI Inference Dependency:** Operates completely without Groq, OpenAI, or Gemini inference calls. No protest records, casualty estimates, historical narratives, or risk forecasts are generated by language models.

## 3. Authenticated Data Sources & Methodological Limits

1. **Mass Mobilization Protest Data (Harvard Dataverse — Clark & Regan)**
   - **DOI:** `https://doi.org/10.7910/DVN/HTTWYL` (CC0 1.0 Public Domain)
   - **Coverage:** January 1990 – March 2020 (~17,145 observations; active protest events have `protest = 1`, while country-year baseline rows have `protest = 0`).
   - **Limitations:** Strictly ends March 2020; records state responses categorically (`arrests`, `beatings`, `shootings`, `killings`) rather than numeric casualty counts; provides locality text or national attribution without point coordinates.

2. **NAVCO Data Project (Harvard Kennedy School Ash Center — Chenoweth et al.)**
   - **Project:** `https://ash.harvard.edu/programs/nonviolent-and-violent-campaigns-and-outcomes-data-project/`
   - **Dataverse Reference (NAVCO 1.3 List):** `https://doi.org/10.7910/DVN/ON9XND`
   - **Coverage:** 1900–2021 (~622–627 maximalist campaigns worldwide).
   - **Limitations:** Campaign-level aggregate dataset (>=1,000 observed participants pursuing regime change, anti-occupation, or secession), not an event catalogue of individual street protests.

3. **GDELT DOC 2.0 API (Recent News Discovery)**
   - **Endpoint:** `https://api.gdeltproject.org/api/v2/doc/doc`
   - **Coverage:** Rolling 3-month digital news index.
   - **Limitations:** News discovery feed only—never treated as a verified protest-event database. Duplicate syndicated coverage is clustered while preserving individual publisher links. Rate-limited upstream to 1 request per 5 seconds.

4. **World Bank Open Data API v2 (World Development Indicators)**
   - **Documentation:** `https://datahelpdesk.worldbank.org/knowledgebase/articles/889392`
   - **Indicators Implemented:** Youth Unemployment (`SL.UEM.1524.ZS`), Total Unemployment (`SL.UEM.TOTL.ZS`), Consumer Inflation (`FP.CPI.TOTL.ZG`), GDP Growth (`NY.GDP.MKTP.KD.ZG`), GDP per Capita (`NY.GDP.PCAP.CD`), Extreme Poverty (`SI.POV.DDAY`), Population (`SP.POP.TOTL`), Urban Share (`SP.URB.TOTL.IN.ZS`), Tertiary Enrolment (`SE.TER.ENRR`).
   - **Limitations:** Missing country-year observations are preserved as `null` (never replaced with `0`). ILO unemployment series are explicitly labelled as `Modelled indicator`. Macroeconomic correlation never implies causal responsibility for individual protests.

## 4. Non-Negotiable Data Integrity Commitments

- **No Fabricated Coordinates:** Events lacking latitude/longitude in the source CSV are never placed on capital cities; country-level summaries use interior geographic centroids with explicit dashed styling and methodological disclaimers.
- **Disaggregated Human Impact:** Fatalities, injuries, arrests, missing persons, displacement, and civic disruptions remain strictly separate and retain source definitions and competing accounts.
- **No Unvalidated Predictions:** Research & Outlook performs descriptive country-year panel matching and exports clean CSV panels for Python/R analysis without displaying invented risk scores or forecast dates.

## 4. Live feeds (ACLED & UCDP) and deployment

- **ACLED** (protests and riots, last 90 days) needs `ACLED_EMAIL` and `ACLED_PASSWORD` in the server environment.
- **UCDP GED / Candidate** (armed-conflict context, last 180 days) needs `UCDP_ACCESS_TOKEN` (request by email via https://ucdp.uu.se/apidocs/).
- Without credentials both show "Not configured" under Data Sources and the rest of the app is unaffected.
- The bundled starter set now holds 30 case studies (2010 to November 2026), including the autumn 2026 France and Germany youth protests.
- See `DEPLOY.md` for a step-by-step Vercel deployment.
